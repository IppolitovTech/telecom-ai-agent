# Настройка роутера

## Первоначальная настройка после установки

После того как монтажник подключил оптический кабель к ONT-терминалу и провёл кабель до роутера:

1. Подключите роутер к ONT-терминалу кабелем в WAN-порт (обычно подписан «Internet» или «WAN», выделен отдельным цветом).
2. Подайте питание на роутер и дождитесь загрузки (1–2 минуты, индикатор питания перестаёт мигать).
3. Подключитесь к Wi-Fi-сети роутера — имя сети (SSID) и пароль указаны на наклейке снизу устройства.
4. Откройте в браузере адрес `192.168.1.1` (для большинства моделей) — откроется веб-интерфейс настройки.
5. Введите логин и пароль администратора (по умолчанию `admin`/`admin`, рекомендуется сменить сразу после входа).
6. В разделе «Интернет» / «WAN» выберите тип подключения **PPPoE**, укажите логин и пароль, выданные при заключении договора (см. в личном кабинете или в договоре).
7. Сохраните настройки — роутер перезагрузится и установит соединение, обычно занимает 30–60 секунд.

Если соединение не устанавливается — проверьте, что кабель от ONT воткнут именно в WAN-порт, а не в один из LAN-портов.

## Настройка Wi-Fi

В разделе «Wi-Fi» / «Беспроводная сеть» можно изменить:

- имя сети (SSID) — рекомендуется использовать латиницу без пробелов;
- пароль — минимум 8 символов, рекомендуется WPA2/WPA3;
- диапазон — 2.4 ГГц (больше дальность, ниже скорость) или 5 ГГц (выше скорость, меньше дальность и хуже проходимость через стены).

Для тарифов от 200 Мбит/с рекомендуется использовать диапазон 5 ГГц, так как 2.4 ГГц физически не может обеспечить такую скорость при большом числе соседних сетей.

## Настройка VLAN на MikroTik

Если используется собственный роутер MikroTik вместо оборудования провайдера, для доступа в интернет часто требуется настройка VLAN (провайдер передаёт трафик в VLAN с идентификатором, указанным в договоре, обычно VLAN ID 100 или значение, выданное при подключении).

Порядок настройки через терминал MikroTik (RouterOS):

```
/interface vlan
add name=vlan100-wan interface=ether1 vlan-id=100

/interface pppoe-client
add name=pppoe-out1 interface=vlan100-wan user=<логин из договора> password=<пароль из договора> disabled=no

/ip firewall nat
add chain=srcnat out-interface=pppoe-out1 action=masquerade
```

После применения конфигурации проверьте статус подключения командой `/interface pppoe-client monitor pppoe-out1` — поле `status` должно показывать `connected`.

Частая ошибка — VLAN ID не совпадает с тем, что указан в договоре: PPPoE-клиент в этом случае будет постоянно пытаться переподключиться без ошибки авторизации. Уточнить корректный VLAN ID для вашего адреса можно в поддержке.

## Проброс портов (port forwarding)

Для доступа к устройствам домашней сети извне (камеры видеонаблюдения, игровые серверы) настройте проброс портов в разделе «NAT» / «Виртуальные серверы» веб-интерфейса роутера, указав внутренний IP-адрес устройства и порт. Для тарифа «Максимум» с выделенным статическим IP проброс портов работает без дополнительной настройки; для остальных тарифов IP-адрес динамический и может меняться при переподключении.
